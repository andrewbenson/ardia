Solara is a Mac browser with Arc's sidebar and Dia's polish, on Chrome's own engine (Chromium 156) built from source.
It has no account, no AI features and no telemetry; uBlock Origin is built in, extensions come from the Chrome Web
Store, and sync, if you want it, runs through your own iCloud Drive. It is a fork of Ardia by Mantra Patel and needs
macOS 26 or later.

## New

- **Developer Mode, as in Arc.** Pages on localhost and other local addresses get Arc's striped toolbar with the full
  URL and port in a monospaced font, edited in place, plus buttons that open DevTools' panels. Their sidebar tabs show
  host and port with a dashed amber border. Turn it on or off for any other site from Site Controls.
- **⌘D moves a tab to Pinned and back, as in Arc.** Bookmark This Page moves to ⌥⇧⌘D.
- **⌘W closes every selected tab, and one ⇧⌘T brings them all back.** As in Arc and Dia, a selection closes together.
  File › Close reads "Close N Tabs" while several are selected.
- **Closing the last tab leaves the window open on a New Tab page, as in Arc and Dia.** ⇧⌘T reopens the tab you
  closed. Pressing ⌘W again on the empty New Tab page closes the window.
- **Settings is a Mac window laid out like System Settings.** Panes sit in groups down a sidebar with colored icons,
  with back and forward in the toolbar and search across every pane.
- **Two app icons.** Settings › Appearance › App Icon offers Classic, the sun setting over a neon grid, and Calm, the
  sun alone on the sky.
- **"Not secure" uses Chrome's own judgment, drawn in Dia's red.** Certificate errors, mixed content and plain http
  pages get a red lock and a red address; pop-up windows' origin strip follows the same verdict.
- **Showing the sync recovery phrase asks for Touch ID or your login password.** That covers showing, copying, sharing
  and saving it, so nobody at your unlocked Mac can read it off.

## Fixed

- **An error in the interface no longer quits the browser.** One unexpected script error could close every window
  without a crash report. Solara now logs it and redraws the part that failed.
- **A session file that can't be read is never overwritten.** If your saved tabs couldn't be read (a permissions or
  disk error), the browser used to start empty and save over them. It now refuses to touch them.
- **iCloud sync holds on to changes through lost, damaged or half-downloaded files.** A Mac that lost its sync state,
  or read a file before iCloud finished downloading it, could miss or undo another Mac's changes. Passwords read from
  a browser that was busy saving them no longer come across with logins missing.
- **Dragging things on web pages works.** Draggable cards and elements (Jira boards, file lists) started a drag that
  never ended, and the page then ignored the mouse.
  Thanks, [@LuisUrrutia](https://github.com/mantrakp04/ardia/pull/425).
- **Site prompts can't be clicked through by the page.** Permission, password, autofill and device prompts ignore
  clicks for their first half second, and a pop-up's permission sheet no longer has Allow as its default button.
  The address bar never runs a pasted javascript: link.
- **A risky download waits for Keep or Discard.** Downloads Chrome flags as dangerous sat at "downloading" forever;
  now the downloads list asks.
- **Each permission prompt shows once.** Answering a camera or location prompt used to bring the same prompt back.

## Smaller

- ⌘-scroll scrolls the page instead of zooming it; ⌘+, ⌘− and pinch still zoom.
- The toolbar stays put while a page scrolls; Settings › Tabs can bring back hiding it.
- ⌘Q asks before quitting, as in Arc and Dia.
- Closing a tab that would take its window along asks first, and the count includes pinned tabs, as Dia's does.
- Sidebar tab titles run to the row's edge until you hover the row.
- The sidebar's Clear button appears only while the pointer is over its divider.
- The toolbar takes the color painted at the top of the page, under Dia's faint 1 pt line, and error pages no longer
  turn it white.
- The address field has no Liquid Glass, as in Arc and Dia.
- The hovered-link bubble keeps Dia's timing, size and truncation.
- ⌘L opens the command bar on the keypress itself.
- Duplicating many tabs at once no longer leaves sidebar rows drawn over each other.
- Clean Up no longer offers to close duplicates you just made.
- Every browser tile fits on onboarding's import step.
- About shows the Chromium version.
